# GROW Dataset

## File
- `samplesuperstore.csv` — the Sample Superstore learning dataset used in the GROW retail sales and profitability case study.

## Purpose
The dataset is used to practice data cleaning, KPI calculation, category and regional comparisons, sub-category profitability analysis, discount analysis, monthly trends, and dashboard development.

## Use in this project
- **Excel:** PivotTables, summary tables, formulas, and charts.
- **SQL:** aggregate queries, grouped comparisons, and data-quality checks.
- **Python:** Pandas-based data checks and KPI summaries.
- **Tableau:** worksheets and the GROW dashboard.

## Important data note
This is sample/learning data, not verified records from a real business. Results describe only the supplied dataset and should not be presented as actual company performance.

## Load the CSV
Open the CSV directly in Excel or Tableau. For the SQL examples, import it into a SQLite database table named `superstore`. See [the SQL analysis file](../sql/grow_analysis.sql) and the [main project guide](../README.md) for details.
